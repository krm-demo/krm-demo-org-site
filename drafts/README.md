# Drafts

Material that is being prepared for the site but is **not part of it**: `scripts/build.sh` copies only `site/`, so nothing here is published to the preview or to krm-demo.org. The repository is public, though, so these files can be read on GitHub.

When a draft is ready, it becomes an article: Markdown in `docs/`, HTML generated into `site/` with `scripts/md-to-html.py`, and a link from the home page.
